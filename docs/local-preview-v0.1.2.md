# v0.1.2 本地测试候选

状态：未发布。先由项目所有者在本机试用，通过后再决定 GitHub 发布；本轮不推送、不创建标签或 Release。

## 修复范围

- 模型将分数写成字符串、评分名称大小写不同、引用空白或弯引号不同等可无损纠正的格式偏差，统一后再次校验。
- 无法唯一对应原文的辅助标注省略并提示；正文、四项分数、中文依据和改进重点仍须完整，缺失时按具体原因重试。不会生成占位分数或拿示例冒充批改。
- Ollama 明确使用 16K 上下文，串行批改。独立范文先写四段英文正文，再评估固定正文；不足 250 个英文词会重试。
- 在线服务可在网页配置、检测、保存、删除；支持 DeepSeek、硅基流动、OpenRouter 和其他兼容接口。首次连接只发送固定检测语句。
- 首次打开只提供本地/在线选择，点击后才下载模型；旧版本用户可主动更新推荐模型。已准备好的引擎在日常启动时恢复，不重复下载。
- 失败和取消保留草稿；测试安装与用户安装、模型、在线设置隔离。

## 实际模型检查

`node --test tests/*.test.mjs`：133 项自动测试通过，0 失败。涵盖格式恢复、评分边界、中文反馈、模式切换、密钥隔离、取消、草稿保留、本地安装与恢复。安装包另按打包后实测结果验收。

在 Windows、约 16 GB 内存、RTX 5080 Laptop GPU 上使用 Ollama + Qwen3.5:4b 完成两篇合成作文的真实分析：

| 场景 | 结果 |
| --- | --- |
| 公共交通是否应免费，含预设主谓一致和不可数名词错误 | 完成，约 55 秒；包含三栏正文、12 个维度分项、中文说明，范文 352 词 |
| 农村人口迁往城市，含预设语法错误 | 在浏览器完成；验证高亮打开解释与练习、独立范文展开，范文 270 词 |

这两篇是专用测试素材，第二篇与报错截图题型相同，不是对用户完整原稿的复测。原始响应只保留于本机忽略目录。计时是本机观察值，不能代表低配置或仅 CPU 的电脑。

Qwen2.5:7b 与 Qwen3.5:4b 均有语义判断不准确、建议过度替换词汇的情况；Qwen3.5:4b 在测试样本中完成了基础纠错和中文结构化反馈。以上检查证明程序流程可用，不能证明 IELTS 评分准确率或所有作文都能通过。重视反馈质量的用户应优先考虑更强的在线模型，并复核重要建议。

本轮未配置商业云端账户密钥，未宣称真实 DeepSeek、硅基流动或 OpenRouter 作文调用已通过；云端适配使用隔离模拟服务验证认证、请求结构、配置持久化、超时和失败路径。用户可在页面用自己的账户做连接和作文试用。

## 配置与费用

推荐本地模型 Qwen3.5:4b 约 3.4 GB，另需 Ollama。自动准备至少需要 12 GiB 内存，建议 16 GB 及独立显卡；更低配置请使用在线入口。网页不会自动转发到陌生免费中转，也不包含共享账号或作者密钥。

- [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/)：使用自己的 API key 和账户额度。
- [OpenRouter 免费路由说明](https://openrouter.ai/docs/cookbook/get-started/free-models-router-playground)：免费模型有额度、频率和可用性限制。
- [Qwen3.5:4b 模型页](https://ollama.com/library/qwen3.5:4b)。

“安装软件后无需下载模型”可通过在线接口实现；“所有用户免账号且长期无限免费”需要维护者提供并承担后端费用，本候选版未包含这种托管服务。
