## 这个版本最重要的两件事

**1. WorkBuddy 改成一键连接，模型可以自己选**

以前要开黑窗口、手打 `/login`。现在在顶部选「WorkBuddy」，点一次「一键连接」，浏览器自动打开官方登录页，登录完面板自己变成「已连接」。不用 API 密钥，用的是这台电脑上已登录账号的额度。

连上之后可以直接在同一个面板里选模型：23 个，分「推荐 / 常用 / 更多」三组，带中文名和一句说明，改完立刻生效。

**2. 修掉两个「一装就废」的问题**

- 覆盖升级后点「一键连接」只报「接口不存在」：旧版本的服务进程还在后台跑，启动脚本看到端口上有应答就直接复用。现在会比对磁盘版本号，不一致就把旧实例停掉再启动。
- 点「一键连接」报 `MODULE_NOT_FOUND`：当前版 WorkBuddy 只带精简产物，网关启动时必须带 `CODEBUDDY_FORCE_LITE_WB_BUNDLE=1`。现在固定带上，双击启动也能连上；失败时的提示也改成了人话，不再把 Node 堆栈甩给用户。

## 一并带来

- **好词好句训练**：批改完成后，用本篇精修稿和范文里真实出现过的表达出题，答完即时判分，可只重练错题。
- **句式仿写**：句式只给骨架、原句和讲解，换三个不同话题各写一句；判分只看句式是否用上、是否完整、是否换成自己的内容，全部在本机完成，不花额度。
- **好词好句前置**：从页面底部搬到写作区正下方，每张卡都能「照着写一句」。
- **免费额度优先**：在线 AI 预设把有免费额度的排在最前（智谱 GLM Flash、腾讯混元 lite 等），默认选中免费的那个。
- **Task 1 传图识图**：PNG/JPG/WebP 直接拖进去，识别结果先进「图表原始信息」等你核对，模糊值标「待确认」，不会拿错的数字打分。

## 说明

- 图片识别需要支持视觉输入的模型（在线视觉模型或本地视觉模型）。
- AI 评分是练习参考，不是官方分数。
- 本机单用户运行，批改内容不出本机（使用在线 AI 时除外，取决于你选的服务商）。
