# 句进 v0.1.2：本地 AI 批改修复与在线 AI 设置

修复本地模型因单个无效标注导致整篇批改失败的问题，并新增面向中文用户的在线 AI 设置。低配置电脑可以连接在线服务，无需下载本地模型或手动编辑配置文件。

## 下载与开始使用

- **Windows 用户推荐：[一键安装版 EXE](https://github.com/wang-qingfeng-dev/ielts-writing-studio/releases/download/v0.1.2/ielts-writing-studio-v0.1.2-windows-x64-setup.exe)**。自带 Node.js，按中文向导安装即可。
- **[免安装便携版 ZIP](https://github.com/wang-qingfeng-dev/ielts-writing-studio/releases/download/v0.1.2/ielts-writing-studio-v0.1.2-windows-x64.zip)**。完整解压后双击 `Start Portable.cmd`。
- 两个下载包适用于 Windows x64。GitHub 自动提供的 Source code 是源码包，不含运行时。

打开后任选一种方式：

1. **在线 AI**：点击「设置在线 AI」，选择服务商，填写自己的 API 密钥，连接检测通过后即可使用。提供 DeepSeek、硅基流动、OpenRouter 和自定义兼容接口。
2. **本地 AI**：点击「一键准备本地 AI」，自动准备 Ollama 和 Qwen3.5:4b。模型约 3.4 GB，自动准备至少需要 12 GiB 内存及 12 GB 可用磁盘，建议 16 GB 内存和独立显卡。首次下载后可离线使用。

## 本次改进

- 可无损恢复的分数格式、维度名称、引号与空白差异自动整理；无法对应原文的辅助高亮会省略并明确提示。
- 正文和四项评分仍严格校验，缺失时按具体原因自动重试，不生成占位分数，不以示例冒充批改。
- 本地批改依次执行，范文分成写作和评估两个阶段；检查英文段落、至少 250 词及中文反馈。
- 在线设置经过连接检测后才保存；密钥留在本机服务端配置中，支持删除连接和记住所选模式。
- 首次打开只展示本地/在线选择，不立即下载模型；修复重试按钮、启动恢复和中文空格路径问题。
- 保留旧模型，只有点击「更新推荐本地模型」才升级；分析失败或取消时保留原稿。

## 从 v0.1.1 更新

先保存当前练习并退出旧版本后台服务，再将新版安装到原目录。继续使用同一浏览器和 `http://127.0.0.1:4318` 可保留原有浏览器记录；建议先导出重要笔记。旧模型不会被删除，看到更新按钮后可主动升级推荐模型。

## 验证与使用范围

133 项自动测试通过；两篇合成作文完成 Qwen3.5:4b 真实批改；网页高亮、练习弹窗、范文展开及刷新恢复经过检查。安装器在隔离的中文与空格目录中完成实际安装和启动检查。

本地小模型仍可能给出不准确的评分或建议，CPU 推理可能耗时数分钟或超时。AI 分数只供练习参考，不是雅思官方成绩或提分承诺。

在线服务需要自己的账户、密钥和可用额度：DeepSeek 按用量收费；免费模型也有次数、频率和可用性限制。本项目没有内置共享密钥或无限免费服务。云端适配通过模拟接口测试，本轮未使用真实云账户验证作文调用。保存的在线密钥是本机用户目录中的明文配置，请勿在共享电脑保存。

附件同时提供 SHA-256 校验文件和构建清单。具体来源、验证内容和局限见[版本验证记录](https://github.com/wang-qingfeng-dev/ielts-writing-studio/blob/v0.1.2/docs/release-verification-v0.1.2.md)。
