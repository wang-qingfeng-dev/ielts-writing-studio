# 句进 v0.1.1 · Windows 64 位免安装包

## 立即体验

1. 将整个 ZIP 解压到一个普通文件夹，不要在压缩包预览窗口内直接启动。
2. 双击 **Start Portable.cmd**。
3. 浏览器会打开 `http://127.0.0.1:4318`，可立即查看有明确标记的教学示例。

这个下载包自带官方 Node.js 24 运行时，无需另外安装 Node、npm 或项目依赖。中文界面、中文批改解释和学习卡片均已包含。应用是本机网页，会在后台运行；关机后再次双击启动即可。首次准备本地 AI 时，页面提供「一键准备本地 AI」按钮。

## 真正批改自己的作文

免安装包不包含 AI 模型、账号额度或 API 密钥。内置示例不是实时批改结果。点击设置页的一键按钮后，程序会自动下载并校验 Ollama、准备本地模型；首次需要联网下载几个 GB，之后可以离线使用。

- 本地模型：推荐直接点击页面的「一键准备本地 AI」。如果你已经自行安装 Ollama，也可以运行 `ollama pull qwen2.5:7b`，然后在页面选择「Ollama 本地」。模型下载较大，运行速度和反馈质量取决于电脑及模型。
- 兼容 API：复制 `.env.example` 为 `.env`，配置 `AI_PROVIDER`、`AI_BASE_URL`、`OPENAI_MODEL` 和你自己的 `AI_API_KEY`，随后重启服务。
- 可选 Codex CLI：需自己安装和登录，使用自己的账号额度。此模式不会自动启用。

详细功能和配置见 [中文项目说明](README.zh-CN.md)。AI 分数只是学习参考，不能替代雅思官方成绩。

## 版本和隐私

应用源码和便携启动器来自 Git 标签 `v0.1.1`。启动器仅临时把随包 Node 加入当前进程 PATH，不修改系统配置。运行时版本、来源网址及校验值记录在 [PORTABLE-MANIFEST.json](PORTABLE-MANIFEST.json)。

Node 原始发行包完整保留在 `runtime/` 下，包括 LICENSE、README、npm 及其依赖许可；`npm install` 不需要执行。项目 MIT 许可证不替代 Node 和模型各自的许可证。

发布包不含作者的 `.env`、API key、真实作文、日志或账号。你的练习记录保存在当前浏览器；使用外部服务时，提交的题目与作文会发送给所选服务。

需要关闭后台服务时，可在任务管理器中查看对应运行时路径，结束本目录 `runtime/` 下的 `node.exe`；不要误结束其他项目的 Node 进程。
