# v0.3.0 桌面测试说明

这是基于 v0.2.0 的本地测试版本，暂不发布 GitHub Release。

## 图片识别

在 Task 1 学术类题型中点击“上传 Task 1 图片”，选择清晰的 PNG、JPG 或 WebP 图表/流程/地图图片，然后点击“识别图片并填入”。识别结果会进入图表材料框，必须检查年份、单位、分类和数值后再开始分析。图片不会直接变成分数，原有 Task 1 提示词仍只使用你确认后的文字材料。

识别需要当前 AI 服务支持视觉输入。文本模型可能返回“模型不支持图片”；此时在在线 AI 设置里选择该服务商的视觉模型，或改用支持图片的本地 Ollama 模型。软件不会把图片发送给未选择的服务商，也不会保存图片到练习历史。

## 桌面窗口

测试包使用 Electron 打开独立软件窗口，内部服务只监听 `127.0.0.1`。它仍然需要本机 AI 或在线 AI 配置；“独立窗口”指运行和使用方式，不代表已有模型会自动变成离线模型。

Windows 测试包启动方式：完整解压后双击 `Start Jujin Desktop.cmd`。测试包包含 Electron 和源码，体积较大；目前没有签名，测试结束后不要把它当成正式安装包分发。

## 测试重点

请优先检查：窗口是否正常打开、Task 1 图片预览、识别结果是否需要人工修正、切换在线 AI 后是否能开始分析、关闭窗口后是否能再次打开，以及 Task 2/Task 1 旧功能是否继续可用。
