# v0.3.0 桌面测试说明

本版验证 Windows 独立窗口、Task 1 图片识别和 iOS 风格的中文工作台布局。当前仍是用户测试版，确认前不会创建 GitHub Release。

## 测试步骤

1. 解压测试包，双击 `Start Jujin Desktop.cmd`。
2. 确认标题栏左侧是句进图标，不再显示 Electron 原子图标。
3. 确认没有 File / Edit / View / Window / Help 默认菜单，软件内的练习记录、复习库和检查更新都在中文工具栏中。
4. 点击顶部“检查更新”，确认更新窗口正常打开。
5. 选择“Task 1 · 学术类图表”，上传 PNG/JPG/WebP，使用支持视觉输入的模型识别。
6. 检查“图表原始信息”：年份、单位、类别和数值需要人工核对，模糊内容应标记为“待确认”。
7. 完成一次分析，确认三栏结果、评分依据和复习卡片仍能使用。

请记录是否仍有错误弹窗、窗口是否能正常关闭、图片识别是否成功、哪个按钮难以找到，以及界面是否出现文字溢出。测试通过后再发布 GitHub Release。
