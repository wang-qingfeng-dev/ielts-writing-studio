# Windows 一键安装说明

v0.1.1 提供 Windows x64 安装程序。安装程序包含应用源码和 Node.js 运行时，不要求管理员权限，也不要求安装 Node.js、npm 或打开命令行。

## 第一次使用

1. 下载 Release 中的 `ielts-writing-studio-v0.1.1-windows-x64-setup.exe`。
2. 双击安装，按中文向导完成安装。可以选择是否创建桌面快捷方式。
3. 安装结束后，应用会自动打开本机的首次设置页。
4. 点击「一键准备本地 AI」。程序会自动下载 Ollama，校验文件、启动本机服务、下载 Qwen2.5 模型，并用一次真实 JSON 请求检查模型是否可用。
5. 进度完成后点击「准备好了，开始写作」，以后从桌面快捷方式启动即可。

首次准备需要联网下载约 3.5–6.5 GB，并建议预留至少 12 GB 磁盘空间。下载过程中页面会显示阶段、字节数和进度；网络中断后可以重试，准备过程可以取消。已经下载的 Ollama 压缩包会尝试断点续传。

## 模型和隐私

本地 AI 固定绑定到 `127.0.0.1:11435`，不向局域网或公网监听。模型保存在当前 Windows 用户的 `%LOCALAPPDATA%\JujinWritingStudio\local-ai` 目录。默认按电脑内存选择 `qwen2.5:7b` 或 `qwen2.5:3b`，不会把模型打进安装包。

题目和作文会发送给本机 Ollama 进行分析。安装器不会写入 API key，也不会自动选择一个来路不明的“免费在线 AI”。如果使用兼容 API 或 Codex，仍需用户自己配置，并且应先确认服务商的隐私和收费条款。

## 常见情况

- **提示空间不足**：释放磁盘空间后点击重试。
- **系统不支持自动准备**：当前一键管理器只支持 Windows x64；可以使用页面中的兼容 API 设置，或从源码按项目说明运行。
- **下载失败**：确认网络可访问 GitHub Release，点击重试。安装器本身不会反复下载已校验通过的 Ollama。
- **模型运行较慢**：本地推理速度取决于内存、显卡和 CPU；小模型可能更快，但输出质量也可能不同。
- **卸载**：卸载程序只删除应用目录，不删除本地模型和浏览器中的练习记录。需要释放模型空间时，可以手动删除上述 `local-ai` 目录。

AI 评分依据 IELTS 四项标准提供练习参考，不是雅思官方成绩，也不承诺固定提分。正式发布包会附带 SHA-256 清单，可用于核对下载文件完整性。
