# Task 1 与在线 AI 使用说明

这些功能包含在 v0.2.0。旧的 v0.1.2 下载包不含 Task 1，请先升级；本文件沿用预览阶段的路径以保留链接。

## 怎么试用

在本项目目录启动应用后，点“新练习”，选择写作题型。

- **Task 1 · 学术类图表**：粘贴完整题目，在“图表原始信息”中填写原图的标题、单位、时间、分类和数据。流程题填写步骤；地图题填写位置与变化。然后粘贴英文作文并分析。目前不直接读取图片，不能用作文代替原图材料。反馈只能核对你实际提供的材料。
- **Task 1 · 培训类书信**：粘贴情境、收信人及全部要点，再粘贴书信。检查写信目的、要点覆盖、语气、称呼和结束语。
- **Task 2**：原有大作文流程保留；“体验完整示例”仍加载明确标记的 Task 2 示例。

Task 1 显示 20 分钟、150 词提示，使用 TA 任务完成度；Task 2 显示 40 分钟、250 词提示，使用 TR 任务回应。其他三项均为 CC、LR、GRA。只评估单篇，不计算整场 Writing 总成绩，也不保证官方分数。

题型、图表文字材料、作文和分析结果一起保存。修改题型或已批改内容时，之前的练习保留在历史记录里。范文可以展开，学习笔记可以导出。

## 在线 AI：第一次设置，以后直接分析

1. 点“设置在线 AI”，选择服务商。
2. 点“登录 … · 获取密钥”，直接打开官方页面。应用页面与草稿保留。
3. 在官方页面登录自己的账号、创建 API Key，然后回到设置窗口粘贴。默认模型已填好；如果账号没有开通该模型，请填写自己的可用模型 ID。
4. 确认数据发送和额度说明，点“连接并使用”。通过简短连接测试后才保存。
5. 后续作文直接点击“开始分析”。原文评分、修订稿、范文及复习卡均显示在当前页面，不必复制到其他聊天网站。

DeepSeek、豆包聊天或元宝的网页版登录状态、聊天会员，不能直接作为本软件的 API 授权。软件不读取这些网站的 Cookie、不代填账号密码，也不把第三方聊天网页嵌入成假登录入口。API 费用/免费额度和模型权限以官方控制台为准。

| 服务 | 接入方式 | 说明 |
| --- | --- | --- |
| DeepSeek | 官方 API | 已有可用配置可直接继续使用 |
| 豆包模型 | 火山方舟 API | 与豆包聊天产品的会员/额度分开 |
| 腾讯混元 | 已有混元云 API 账户 | 与元宝登录分开；官方正迁移至 TokenHub，新账号可按官方说明使用其他兼容接口 |
| 硅基流动 | 官方兼容接口 | 需填写账号可用模型，费用与免费额度以控制台为准 |
| OpenRouter | 免费模型路由或自选模型 | 需要密钥，有限流和模型可用性变化 |

没有官方第三方登录授权接口时，首次复制 API 密钥仍不可省略。之后密钥只在本机应用配置中保存，不进入作文记录；切换服务不会把上一家的密钥发给下一家。
