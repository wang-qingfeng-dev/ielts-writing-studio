## 本地模型验证

Qwen3.5:4b 初次 Task 1 测试暴露了混合题型指令和段落格式问题，错误输出被拒绝。已将学术报告、书信写作指令分开，写作阶段移除评分要求，并增加段落和误写书信的校验。

修复后的学术类独立范文两阶段实测通过：写作 33 秒、评分 93 秒，范文 189 词。随后完整图表题流程通过：66 秒、范文 161 词、TA/CC/LR/GRA。书信题复测发现其自然称呼/落款不适合强制四项段落数组，已改为冻结完整书信正文并验证至少三段展开内容；书信评分使用明确的中文指令。完整书信流程通过：45 秒、范文 196 词、3 条问题、TA/CC/LR/GRA。曾尝试将书信中文评分提示同时用于图表题，但图表评分校验失败，最终图表题恢复其此前已通过的提示。小型模型仍有输出波动，不能把单次通过等同于所有作文稳定成功；建议小白优先使用已配置的在线 AI。

测试也暴露出旧版关闭 Ollama 时遗留推理子进程，导致重复测试时内存压力增加。已修复为仅结束本管理器拥有的进程树；修复后的测试退出未留下对应进程。自动测试使用模拟磁盘余量，避免因开发机 C 盘不足而误判安装流程。

最终题型分流代码再次实测图表题通过：55 秒、范文 178 词、TA/CC/LR/GRA。修订正文有效，但该次本地输出没有保留下可用问题标注；因此不将这次格式校验成功表述为标注质量已达到在线模型水平。书信仍使用前述 45 秒实测通过的独立路径。
