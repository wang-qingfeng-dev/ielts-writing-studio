# v0.3.1 桌面测试包

这是给 Windows 测试用的独立窗口包。双击 `Start Jujin Desktop.cmd` 后，会打开一个正常的软件窗口；不需要手动打开浏览器。关闭软件窗口即可结束本次桌面程序。

本版修复了部分启动方式下的 Electron `EPIPE` 错误弹窗，并移除了默认的 File / Edit / View / Window / Help 菜单；练习记录、复习库和检查更新都在中文工具栏中。

Task 1 图片识别需要在“设置在线 AI”中使用支持视觉输入的模型。上传后先检查“图表原始信息”中的年份、单位和数值，再点击开始分析。识别不清的内容会标为“待确认”，请人工核对。

此包是用户确认前的测试版本，不代表正式 Release。请不要把测试包当成最终公开安装器。
